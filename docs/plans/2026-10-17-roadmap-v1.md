# ApplyDiff — Roadmap sisa kerjaan (v1.0)

Status: plan induk · Owner: F Y Pahlevi · Date: 2026-10-17

## Posisi sekarang

Fondasi selesai dan sudah di main:

- Go core: job, source, scan, match, cv, tailor, diff, filter, extract,
  application, store, export, llm
- CLI 14 subcommand (cobra, `--json`, `--dry-run`, exit 0/2/3/4/5)
- TUI Bubble Tea 5 layar
- Web Nuxt Phosphor + keyboard shortcuts
- Satu binary dengan web ter-embed, PDF ke `output/`, Dockerfile,
  release script
- Migrasi timestamp (`2026010100000N_*.sql`)
- 16 package test hijau

Belum ada sama sekali:

- Modul interview prep (plan ada, kode nol)
- Scam guard + channel (plan ada, kode nol)
- Data nyata (DB kosong, belum pernah scan beneran)
- Demo visual (GIF/screenshot) dan README yang menjual

Plan ini menyatukan semuanya jadi urutan yang bisa dieksekusi, satu fase satu
PR, semuanya ke `main`, semua commit atas nama owner.

## Prinsip yang berlaku di semua fase

- **DB-first.** SQLite satu-satunya sumber state. Disk cuma `output/`.
- **No auto-submit.** Apply manual default.
- **Grounded.** Angka dan klaim harus ada sumbernya (facts gate).
- **Satu core, tiga muka.** Logika di `internal/`, UI di `cmd/` + `web/`.
- **Phosphor locked.** Gak ada warna baru.
- **No CI.** Gak ada `.github/workflows`.
- **Test wajib.** Tiap fase nambah test, bukan ngurangin.

## Fase 1 — Interview prep core

Plan detail: `docs/plans/2026-10-17-interview-prep.md`

Migrasi `20260101000007_interview.sql`:

- `interview_kit` (application_id, loop, topics, prompts, questions)
- `story_bank` (category, situation, task, action, result, learning, evidence)
- `mock_session` (application_id, type, prompt, started_at, finished_at)
- `mock_step` (session_id, index, name, timebox_s, output, note, weak)
- `rubric_score` (session_id, dimension, score 1–5, comment)
- `topic_note` (slug, title, body, tier)
- `drill` (topic_slug, prompt, minutes)

Seed:

- 5 framework: system design, coding, behavioral, business case, product case
- System design 6 langkah + timebox + output wajib per langkah
- Mindset 7 pelajaran
- 13 topic_note
- 6 kategori story + rubrik 5 dimensi per tipe

Paket:

- `internal/interview/` — framework registry, kit generator, scoring,
  story validation (gate fakta)
- `internal/store/interview.go` — CRUD

Perintah:

- `applydiff interview kit <job-key>`
- `applydiff interview mock <job-key> --type ...`
- `applydiff interview drill <topic>`
- `applydiff interview story add|list`
- `applydiff interview score <session-id>`
- `applydiff interview export <job-key>` → `output/`

TUI: tab Interview (kit, timer, rubrik, story). Web: `/interview/[job-key]`.

Acceptance: kit bisa digenerate dari JD nyata, mock nyimpan skor, cerita tanpa
bukti fakta ditolak, `go test` hijau.

## Fase 2 — Scam guard + channel

Plan detail: `docs/plans/2026-10-17-scam-guard-channel.md`

Migrasi `20260101000008_risk_channel.sql`:

- job: `risk`, `flags`
- application: `channel`, `referrer`, `notes`

Paket `internal/risk/`: aturan keras + lunak, `Assess(job) -> {score, flags}`.

Permukaan: `scan --min-risk`, badge di TUI/Web, `applydiff stats` (reply rate
per channel), filter `posted_within` + skor prioritas.

Acceptance: satu test per aturan keras, `stats` nampilin angka nyata, filter
freshness jalan di scan + feed.

## Fase 3 — Data nyata + demo

- Tambah source nyata (Jobicy, Remotive, RemoteOK, WeWorkRemotely, Working
  Nomads) di samping Greenhouse
- Scan beneran ke DB
- Isi CV master contoh yang lengkap (facts file)
- Alur end-to-end: scan → match → tailor → diff → approve → build PDF
- Screenshot 6 layar web + 1 GIF 15 detik (scan → diff → approve → PDF)

Acceptance: `applydiff jobs --json` balikin job nyata, PDF kebentuk di
`output/`, GIF ada di `docs/`.

Acceptance: orang bisa clone → jalan dalam 2 menit, atau download binary dan
langsung `applydiff serve`.
